Seasonal map themes

One OpenStreetMap base style, re-themed per season with MapLibre GL JS.

How it works

Each theme is a small JSON file of color overrides applied to the base style's layers (land, water, parks, roads, buildings, labels). The base style and tiles come from OpenFreeMap, built on OpenStreetMap data, so adding a new season is just a new palette. Seasonal icons are drawn as map symbols inside the style, so they move, scale and collide with labels like any other map feature. Falling snow is an optional overlay that never blocks panning or zooming and stays off for anyone who prefers reduced motion.
